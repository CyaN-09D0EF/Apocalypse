# 황무지의 백합 — v0.4 주간 진행 시험판

이치로 약탈무리 거점을 돌아다니며 일하고, 사람들과 관계를 쌓는 Godot 프로젝트입니다.

## 실행

압축을 모두 푼 뒤 Godot 4.5.1 이상 4.x 일반판에서 `project.godot`를 가져오고 F5를 누르세요.
별도 플러그인은 필요하지 않습니다. Windows 실행 파일이나 APK가 아닌 소스 프로젝트입니다.

## 일주일 단위 진행

- 한 턴은 일주일이며, 숙소의 `이번 주 마무리` 버튼으로 다음 주로 넘어갑니다.
- 52주를 1년으로 계산합니다. 15세부터 시작해 260턴 뒤 20세가 됩니다.
- 상단에 현재 주차와 나이, 남은 자유활동 시간을 표시합니다.
- 한 주의 일상 노동·수면 등은 요약하고, 플레이어가 선택할 주요 자유활동에 14시간을 배분합니다.
  이동 10분, 창고 일 2시간, 훈련 90분 등은 이 주간 활동 예산에서 차감합니다.
- 창고 일·훈련·정비·주요 대화·식량 전달의 반복 제한은 주 단위로 초기화합니다.
- 이번 주에 카르에게 구입을 부탁하면 다음 주 시작에 식량을 받습니다.
- 식량 1꾸러미는 일주일치 보충식으로 추상화한 자원입니다.

## 백합의 건강

시작 건강은 40입니다. 기본 배급만 받는 주에는 건강이 2 감소하고, 30에서 멈춥니다.
이치가 매주 한 번 보충식 1꾸러미 또는 3꾸러미를 건넬 수 있습니다.
즉시 건강이 오르지 않고, 백합의 보관 식량에 쌓입니다.

주를 넘길 때 보관 식량을 최대 2꾸러미 소비합니다.
1꾸러미면 건강이 유지되고, 2꾸러미면 건강이 3 회복되며 상한은 100입니다.
방문하지 않는 주에도 비축 식량을 소비합니다. 식량이 끊기면 다시 건강이 감소합니다.
기록에 주간 식사·건강 결과가 표시되고, 건강 수준에 따라 거처의 상태 묘사가 달라집니다.

이치의 포만감은 활동하면 내려가고 식사를 보충하면 올라갑니다.
기력이 부족하거나 배고픈 주를 보내면 회복에도 영향을 받습니다.

## 지도

건물이나 이름표를 클릭하면 이치가 통로를 따라 이동합니다. 다음 11개 장소가 있습니다.
식량창고·배급소, 훈련장, 차량정비소, 공동 숙소·취사장, 안쪽 거처,
중앙 공터, 무기고, 급수장, 의무실, 정문·망루, 보스 관리동.

기존 일·훈련·정비·대화·음식과 꽃 전달 기능은 연결되어 있습니다.
새 시설은 지도와 현장 설명까지 구현했습니다. 독립 지도 장면은 `scenes/camp_map.tscn`입니다.

## 저장·불러오기

수동 슬롯은 6개입니다. 저장 이름을 정하고 슬롯을 선택해 저장합니다.
목록에는 주차·나이·장소, 상세 정보에는 실제 저장 시각과 상태·물자·백합의 식량이 표시됩니다.
덮어쓰기와 불러오기는 확인창을 거칩니다. 빈 슬롯과 손상된 저장은 불러올 수 없습니다.
`새 시작`은 현재 진행만 초기화하며 저장은 지우지 않습니다. 자동 저장은 없습니다.

이전 단일 저장은 `이전 버전 저장` 항목에서 불러올 수 있습니다.
원본은 유지되며 불러온 진행을 새 슬롯에 저장하면 됩니다.
v0.3 슬롯도 불러올 수 있습니다. 기존 경과 일수를 주차로 환산하고 자원·관계·식량을 유지합니다.
기존 활동 제한은 해당 주의 제한으로 이어집니다. v0.1~v0.2의 건강 30 미만은 30으로 보정합니다.

저장 위치는 Godot의 `user://saves/slot_01.json`부터 `slot_06.json`까지입니다.
Windows 기본 경로는 `%APPDATA%/Godot/app_userdata/황무지의 백합 · 견습의 일주일/`입니다.
프로젝트 내부 이름은 기존 저장 경로와 호환되도록 유지했습니다.

## 구현 범위

주차·나이 변화와 스무 살까지 남은 주 수는 실제 계산됩니다.
스무 살의 동쪽 이송 사건, 보스 교체, 정착지 운영은 아직 발동하지 않습니다.
질병·부상·치료·감시 판정·음식 압수·NPC 자율 일정·실제 전투도 아직 구현하지 않았습니다.
날씨는 고정이고 수치 균형은 시험용입니다. 인물 화면은 알려진 수치를 직접 표시합니다.

## 검사

Godot 4.5.1 Linux에서 규칙 검사 66개와 11개 장소의 클릭 이동·화면 배치를 확인했습니다.
Windows 직접 실행과 APK 내보내기는 검사하지 않았습니다.

```sh
godot --headless --path . --script tests/test_state.gd
godot --headless --path . --script tests/test_saves.gd
godot --headless --path . --script tests/test_health.gd
godot --headless --path . --script tests/test_weeks.gd
godot --headless --path . -- --smoke-ui
```

검사는 전용 test_ 파일을 사용하며 실제 슬롯 저장을 덮어쓰지 않습니다.
지도와 인물은 코드로 그렸으며 생성 이미지는 사용하지 않았습니다.
Noto Sans KR의 OFL 라이선스는 `assets/FONT_LICENSE.txt`에 있습니다.
